Webサイト 操作ガイド

このガイドでは、生徒の提出物をWebサイトに掲載するまでの手順を説明します。
慣れると「ボタンを押すだけ」で公開できます。

はじめに

サイトの概要

このWebサイトは、探究発表会のスケジュール一覧と各グループの資料（PDF）を生徒・保護者・教員が閲覧できるようにするものです。

ページ内容閲覧者
スケジュール一覧
/index.html		 全グループの時間帯・教室・テーマ一覧。クリックで詳細へ 全員
グループ詳細
/group.html		 探究テーマ・概要・レポートPDF・発表スライドPDF 全員
ℹ️
PDF・スライドの保管場所 PDFファイルはこのサイトには置きません。Google Drive に保存したままで、サイトはそのリンクを表示するだけです。Driveの共有を「組織内のみ」に設定すれば、ファイルの中身は学校のアカウントでないと開けません。
はじめに

全体の流れ

1
生徒 Google Slides で資料を作成・提出

レポート用・発表スライド用の2種類を Classroom に提出。

2
教員 締切後、スプレッドシートのボタンをクリック

「⚡ すべて一括実行」を押すだけ。あとは自動で進みます。

3
自動 Classroom から提出物を取得・グループIDで整理

提出したファイルをグループIDと紐付けます。

4
自動 Google Drive でPDFに変換・共有リンクを取得

SlidesをPDFに変換し、「組織内のみ」で共有します。

5
自動 スケジュールデータをサイトに公開（約3〜5分）

データファイルが更新され、Vercel が自動でデプロイします。

✓
全員 Webサイトで閲覧・PDFを確認

サイトURLを開くとスケジュールと資料が表示されています。

初回セットアップ（1年目のみ）

① Google スプレッドシートを準備する

⚠️
初回のみの作業です 一度設定すれば、翌年以降はグループ一覧を更新するだけで使い続けられます。
  1. Google スプレッドシートを新規作成する Google Drive を開き、「新規 → Google スプレッドシート」を作成。名前は「総合探求 発表会管理」など分かりやすい名前にする。
  2. Apps Script エディタを開く スプレッドシートのメニューから拡張機能 → Apps Script を選択。
  3. コードファイルを貼り付ける apps-script/ フォルダ内の .gs ファイルの内容をコピーして、Apps Script エディタに貼り付ける（各ファイルごとに別のスクリプトファイルを作成）。
  4. 「初期セットアップ」を実行する スプレッドシートに戻るとメニューに「📋 発表会サイト管理」が追加されます。
    📋 発表会サイト管理 → 🔧 初期セットアップ（シート生成） を実行。

初回セットアップ（1年目のみ）

③ GitHub トークンを取得・入力する

スクリプトがサイトのデータファイルを自動更新するために、GitHubの「パーソナルアクセストークン」が必要です。

  1. GitHub にログインし、Settings を開く 右上のアイコンをクリック → Settings
  2. Developer settings → Personal access tokens → Tokens (classic) 左メニューの一番下にあります。
  3. 「Generate new token (classic)」をクリック repo にチェックを入れて「Generate token」。
  4. 表示されたトークンをコピー ⚠ 一度しか表示されません — 必ずコピーしてから閉じる。
  5. スプレッドシートの「設定」シートに貼り付ける 「GitHub Token」の行のB列に貼り付ける。

よくある質問

スクリプト実行時に「権限エラー」が出る ▼
初回実行時はGoogleの認証画面が出ます。「詳細を表示」→「（アプリ名）に移動」→「許可」の順に進んでください。「安全でない」と表示されますが、自分で作成したスクリプトなので安全です。
一部のグループのPDFだけ変換されていない ▼
「生徒対応」シートに氏名が登録されていない生徒の提出物は処理されません。生徒対応シートを確認し、漏れている生徒を追加してから「② PDFに変換」→「③ サイトに反映」を再実行してください。
サイトを開いてもスケジュールが更新されていない ▼
Vercelのデプロイに2〜3分かかります。しばらく待ってからブラウザをリロード（Ctrl+Shift+R / Cmd+Shift+R）してください。それでも更新されない場合は、Vercelのダッシュボードでデプロイ状況を確認してください。
「GitHub API エラー」と表示される ▼
GitHubトークンの有効期限が切れている可能性があります。GitHubで新しいトークンを発行し、「設定」シートの「GitHub Token」を更新してください。
翌年も同じ仕組みを使いたい。何を引き継げばよいか？ ▼
  • Google スプレッドシート（「設定」シートの値をそのまま引き継げる）
  • GitHub リポジトリ（変更不要）
  • Vercel プロジェクト（変更不要）
  • このガイドHTML（docs/teacher-guide.html）
「グループ一覧」と「生徒対応」シートだけ毎年更新すれば使い続けられます。
